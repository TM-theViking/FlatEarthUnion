# How to Contribute

## Current Categories
We currently accept documents in these broad categories:
1. 'FEU-Documents/Celestial-Navigation/'
2. 'FEU-Documents/NaturalScience-ScientificMethod/'
3. 'FEU-Documents/Physics/'
4. 'FEU-Documents/Geography/'

## Adding a New Category
If your document does not fit into the categories above, you may propose a new folder.
1. **fork** this repository.
2. Create a new folder in 'FEU-Documents/' (e.g., 'FEU-Documents/YourNewCategoryFolder/').
3. Submit a **Pull Request**.
   * *Note:* New categories require moderator approval to maintain organization.
  
## File Naming
Please use clear, descriptive names (e.g., 'oceanography/bathymetric-analysis.pdf' instead of 'New-Folder/doc1.pdf').
